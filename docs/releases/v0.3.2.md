# Andriloft 0.3.2

This is a planned patch following the published `v0.3.1` release. Publication and available downloads are recorded on the [latest published GitHub release](https://github.com/culpen90/Andriloft/releases/latest).

## Changes

- Preserve exact UTF-16 identity for DEX class names. Valid obfuscated APKs with distinct composed and decomposed Unicode names previously failed duplicate-class validation immediately after marketplace download because Swift string equality treated those names as equivalent.
- Accept valid APKs with highly compressed assets that previously failed validation immediately after marketplace download. The ZIP reader keeps its 128 MiB expanded-entry limit, 512 MiB total expansion limit, bounded decompression, declared-length checks, and CRC validation.
- Report unsupported archive or DEX formats and importer limits separately from malformed APKs, instead of describing every validation failure as an invalid standalone APK.
- Update local development bundle defaults to `0.3.2 (10)`. Distributed releases continue to receive the planned semantic version and exact source commit-count build number from release automation.

## Current functionality and limits

This patch corrects DEX identifier handling, APK validation, and marketplace error messages. It adds no Android API or native-library support. Unity games and other apps requiring JNI/Linux native libraries remain unsupported. A successful download does not establish that an APK can run; downloaded code never runs automatically.

The bundled example continues to support basic Java activities, native controls, click callbacks, text input, and saved preferences. AndroidX, Compose, XML layout inflation, Google Play services, WebView, and Android network/media/device services remain unsupported. See the [README](../../README.md#current-limits), [marketplace guide](../MARKETPLACE.md), and [validation record](../../VALIDATION.md) for implemented features and observed checks.

## Download and install

Use the [latest published GitHub release](https://github.com/culpen90/Andriloft/releases/latest) for current downloads. Each release provides a universal macOS DMG and ZIP, a signed update feed, checksums, and source metadata. macOS 13 or newer is required; signing is ad hoc without Apple notarization. Follow the [installation guide](../INSTALL.md) for first launch and in-app updates.
