# Andriloft 0.1.0

The first public release includes the ready-to-run macOS app, built in Swift Release configuration. Andriloft executes supported Android APK DEX bytecode and maps Android framework calls to native Mac controls. It does not boot Android or require an Android SDK at runtime.

## Included

- APK import through the library, drag and drop, or Finder's Open With menu.
- Managed DEX execution, activity lifecycle callbacks, Java button listeners, editable text, and package-isolated saved preferences.
- Native controls for a subset of `LinearLayout`, `TextView`, `Button`, and `EditText`.
- A bundled Android example that demonstrates a counter, text input, a greeting, and saved state.
- Explicit diagnostics for unsupported APIs and opcodes.

## Download and install

Download `Andriloft-0.1.0-macOS-universal.dmg` or `Andriloft-0.1.0-macOS-universal.zip` from the [v0.1.0 release](https://github.com/culpen90/Andriloft/releases/tag/v0.1.0). Both contain the same app for macOS 13 or newer, with Apple Silicon and Intel executables. `SHA256SUMS.txt` and `release.json` provide checksums and build metadata.

The app is ad hoc signed, without Developer ID signing or Apple notarization. Distribution requires no paid Apple Developer account. macOS may block the first launch; the [installation guide](https://github.com/culpen90/Andriloft/blob/v0.1.0/docs/INSTALL.md) explains Apple's per-app **Open Anyway** process.

## Compatibility and validation

This is an experimental compatibility subset. Most third-party Android apps will not run. AndroidX, Compose, XML layout inflation, Google Play services, WebView, services/Binder, networking/media/device APIs, JNI/Linux native libraries, split APKs, and Android exception handling are not implemented. Native libraries are never loaded. APKs run in Andriloft's process, without a hostile-APK sandbox or APK certificate verification.

The included real APK fixtures cover native controls, managed callbacks, saved state, lifecycle ordering, activity completion, and unsupported-API errors. The test suite contains 23 tests. Native GUI validation was performed on Apple Silicon; physical Intel Macs and older supported macOS versions have not been exercised. The release manifest records execution checks for each tested architecture. See [VALIDATION.md](https://github.com/culpen90/Andriloft/blob/v0.1.0/VALIDATION.md) for the recorded checks.
